# NeuroEnf — Guia de Enfermagem em Neurologia (adulto)

App web de apoio à equipa de enfermagem em Neurologia: temas clínicos, sinais de alarme, escalas interativas e guia farmacológico.
Instalável no telemóvel e utilizável sem rede.

**Abrir:** https://mivieira86-boop.github.io/neuroenf/

Ferramenta de apoio à prática: não substitui os protocolos institucionais, a prescrição médica nem o RCM dos medicamentos.
